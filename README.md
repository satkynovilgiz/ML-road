## 🗺️ The path

```mermaid
flowchart LR
    A["Python + math"] --> B["Machine learning"] --> C["Deep learning"]
    C --> D["LLMs + RAG"] --> E["AI agents"] --> F["Production"]
```

| Stage | Learn | Build |
| --- | --- | --- |
| **01 · Foundations** | Python, NumPy, linear algebra, probability | Explore and visualize a dataset |
| **02 · Machine learning** | Regression, classification, clustering, evaluation | Train a classifier and explain its errors |
| **03 · Deep learning** | Neural networks, backpropagation, PyTorch, transformers | Build an image or text classifier |
| **04 · LLM engineering** | Embeddings, retrieval, RAG, structured outputs | Create document Q&A with citations |
| **05 · Agents** | Tool use, state, MCP, human oversight, evaluation | Build and test a tool-using assistant |
| **06 · Production** | APIs, monitoring, security, cost, reliability | Deploy and measure an AI application |

The stages are a guide, not a required sequence. Build small projects while you learn.

## 📚 Start with these resources

| Area | Resource | Why start here |
| --- | --- | --- |
| ML | [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) | Applied fundamentals and exercises |
| Deep learning | [Dive into Deep Learning](https://d2l.ai/) | Explanations with executable code |
| Computer vision | [Stanford CS231n](https://cs231n.stanford.edu/) | Vision models and deep learning |
| NLP | [Stanford CS224N](https://web.stanford.edu/class/cs224n/) | Language models and NLP |
| LLMs | [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1) | Transformers and hands-on tools |
| Agents | [Building Effective Agents](https://www.anthropic.com/research/building-effective-agents) | Clear agent patterns and tradeoffs |
| MCP | [Model Context Protocol documentation](https://modelcontextprotocol.io/introduction) | Tools, resources, and integrations |

For deeper reading, see the [ReAct](https://arxiv.org/abs/2210.03629) and [Toolformer](https://arxiv.org/abs/2302.04761) papers. Resource links lead to their original publishers whenever possible.
